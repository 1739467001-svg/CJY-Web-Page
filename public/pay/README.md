# 收款码 / Payment QR codes

服务清单的「扫码支付」弹窗会读取这个目录下的两张收款码图片：

| 支付方式 | 文件名 | 说明 |
|---|---|---|
| 微信支付 | `wechat.png` | 微信「收付款 → 二维码收款」保存的图片 |
| 支付宝 | `alipay.png` | 支付宝「收钱」页面保存的收款码图片 |

## 怎么放

1. 分别把你的**微信收款码**和**支付宝收款码**导出为图片；
2. 重命名为 `wechat.png`、`alipay.png`；
3. 放到本目录（`public/pay/`）下，覆盖同名占位即可，**无需改代码**。

- 建议：正方形、≥ 500×500、背景干净（纯色最好，方便扫描）。
- 图片缺失时弹窗会显示一个提示占位框，不会破版。
- 个人收款码一般**不含固定金额**：弹窗已提示用户「扫码后手动输入金额 + 备注服务名」，这是正常的收款流程。

> 想要固定金额、自动到账，可在微信/支付宝里生成**指定金额的收款码**，一档服务一张图，再按需替换。
