# 收款码 / 联系码

支付弹窗与「先聊聊」弹窗读取本目录下的三张图（**真 PNG**，不是改扩展名的 JPEG）：

| 用途 | 文件名 | 内容 |
|---|---|---|
| 微信支付 | `wechat.png` | 微信收款码 + 收款人「俊烨」 |
| 支付宝 | `alipay.png` | 支付宝收款码 + 收款人「鼻炎宁」 |
| 加好友 / 回执 | `contact-wechat.png` | 个人微信名片码（先聊聊、付款回执用） |

## 换码怎么做

1. 导出新的收款码 / 名片码截图；
2. **裁掉彩色大背景**，只保留「二维码 + 下方姓名」那块白卡；
3. 存成**真 PNG**（不要把 `.jpg` 直接改名成 `.png`——nginx 开了
   `X-Content-Type-Options: nosniff`，扩展名与实际格式不符会被浏览器拒绝渲染）；
4. 覆盖同名文件即可，**无需改代码**。

- 建议宽度 400–700px，纵向比例接近 20:23（弹窗按这个比例留框）。
- 图片缺失时弹窗显示占位提示，不会破版。
- 个人收款码不含固定金额：弹窗已提示用户「手动输入金额 + 备注服务名」，这是正常收款流程。
  想要固定金额可在微信/支付宝生成**指定金额收款码**，一档服务一张图再替换。
